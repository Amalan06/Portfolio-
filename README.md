# Portfolio — Amalan Venkatesan

Personal portfolio site built with HTML, CSS, and JavaScript. No frameworks, no dependencies.

🔗 **Live site:** https://amalan06.github.io/Portfolio-

---

## Built With

- HTML
- CSS
- JavaScript

## Sections

- **About** — Background, education, and quick facts
- **Skills** — Languages, tools, and concepts
- **Projects** — Personal and academic projects
- **Experience** — Work history
- **Contact** — Links to email, LinkedIn, and GitHub

## Run Locally

No build step required. Just open the file:

```bash
open index.html
```
